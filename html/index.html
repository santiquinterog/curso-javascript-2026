Un recorrido práctico por los fundamentos y conceptos clave del desarrollo web moderno: desde HTML y CSS hasta JavaScript avanzado con asincronismo y persistencia de datos. Cada sección es un módulo independiente con ejemplos listos para explorar.

🎨 CSS

CSS Básico

Selectores, propiedades tipográficas, colores, la propiedad display y sus modos: block, inline e inline-block. El punto de partida para estilizar cualquier página.

Flexbox

Diseño de layouts con CSS Flexbox: ejes principal y cruzado, alineación, wrap, gap, flex-grow, order y align-self en la práctica.

Formularios Básicos

Construcción de formularios HTML: campos de texto, radio buttons, checkboxes, color picker, selector de hora, rangos y más tipos de input nativos.

Manipulación del DOM

Cómo seleccionar, crear, modificar y eliminar nodos del DOM. Uso de getElementById, querySelector, eventos de mouse, teclado e interacción dinámica en tiempo real.

Ir al módulo → ⚙️ JS

JavaScript Básico

Variables, tipos de datos, operadores, condicionales, funciones, objetos, strings, arrays y bucles: todos los bloques fundamentales del lenguaje.

Asincronismo

Los tres modelos de código asíncrono en JavaScript: callbacks, promesas (Promise) y la sintaxis moderna async/await. Comparación práctica entre los tres enfoques.

LocalStorage

Persistencia de datos en el navegador usando localStorage: guardar, leer y eliminar datos sin necesidad de un servidor. Demo con lista de usuarios que sobrevive recargas de página.
